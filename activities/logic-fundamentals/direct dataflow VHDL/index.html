01

Understanding VHDL Dataflow

VHDL is a hardware description language used to describe digital circuits. In this activity, you will use dataflow descriptions to represent logic gates.

A VHDL design generally contains two important parts:

  • Entity: Describes the external interface of the circuit, including its inputs and outputs.
  • Architecture: Describes how the circuit operates.

Example: Inverter (NOT Gate)

library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity inverter is
    port (
        I : in  std_logic;
        O : out std_logic
    );
end entity inverter;

architecture dataflow of inverter is
begin
    O <= not I;
end architecture dataflow;
Remember:

The entity describes the interface, while the architecture describes the operation.

AND: Output is 1 only when both inputs are 1.

OR: Output is 1 when at least one input is 1.

XOR: Output is 1 when the inputs are different.
