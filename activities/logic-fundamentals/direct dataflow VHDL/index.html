VHDL Explorer 01: Direct Dataflow Logic Gates

Learn how to describe basic logic gates using VHDL direct dataflow statements. Explore an inverter, create AND, OR and XOR gates, and test how your VHDL code behaves.

Estimated time: 30–45 minutes

Before you begin

What is direct dataflow?

Describe what the output should do by writing a logical expression.

VHDL is a hardware description language. It allows us to describe the behaviour and structure of digital circuits. In this activity, you will use direct dataflow descriptions to describe basic logic gates.

A direct dataflow statement describes how a signal is calculated from other signals. For example: 

O <= not I;

This statement means that the output signal O receives the opposite logical value of the input signal I.

Learning objectives

  • Understand the purpose of an entity and an architecture.
  • Recognise the basic structure of a VHDL design.
  • Use VHDL operators to describe NOT, AND, OR and XOR gates.
  • Predict the outputs of logic gates using truth tables.
  • Write a direct concurrent assignment in a dataflow architecture.

What you should already know

Digital circuits use two main logic values: 0 (LOW) and 1 (HIGH). These values are used to represent binary information.

Part 1

Understanding the VHDL structure

Every basic VHDL design needs an interface and an implementation.

A basic VHDL design is divided into two important sections: the entity and the architecture.

Entity The interface

Defines the inputs and outputs that communicate with the outside of the circuit.

Architecture The operation

Describes how the circuit works and how its outputs are calculated.

Important VHDL keywords

VHDL keyword reference
Keyword Purpose
library Includes a library containing useful definitions.
use Makes definitions from a package available.
entity Declares the circuit's name and interface.
port Declares the circuit's inputs and outputs.
in Identifies an input signal.
out Identifies an output signal.
std_logic Defines a standard logic signal type.
architecture Describes the circuit's behaviour or structure.
<= Assigns a value to a signal.

The IEEE STD_LOGIC_1164 package provides the std_logic signal type and standard logic operators.

Part 2

Explore the inverter (NOT gate)

Start with one input and observe how the output changes.

An inverter, also called a NOT gate, produces the opposite logical value of its input. If the input is 0, the output is 1. If the input is 1, the output is 0.

VHDL code for an inverter

library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity inverter is
    port (
        I : in  std_logic;
        O : out std_logic
    );
end entity inverter;

architecture dataflow of inverter is
begin
    O <= not I;
end architecture dataflow;

Understanding the code

  • library IEEE; makes the IEEE library available.
  • use IEEE.STD_LOGIC_1164.ALL; makes the standard logic definitions available.
  • entity inverter is declares a circuit named inverter.
  • I : in std_logic declares one input called I.
  • O : out std_logic declares one output called O.
  • architecture dataflow begins the circuit's implementation.
  • O <= not I; assigns the opposite value of I to O.

Syntax reminder: Each port declaration is separated by a semicolon, but the final port declaration does not have a semicolon after its type.

Part 3

Create AND, OR and XOR gates

Use two inputs and one direct dataflow assignment.

You will now create three logic gates. Each gate has two inputs, A and B, and one output, Y.

1. AND gate

The AND gate produces an output of 1 only when both inputs are 1. 

entity and_gate is
    port (
        A : in std_logic;
        B : in std_logic;
        Y : out std_logic
    );
end entity and_gate;

architecture dataflow of and_gate is
begin
    Y <= A and B;
end architecture dataflow;

The OR gate produces an output of 1 when at least one input is 1.

Extend your knowledge

Key takeaway

What you should remember

  • Entity = interface: defines the inputs and outputs.
  • Architecture = operation: describes how the circuit works.
  • Direct dataflow: uses concurrent signal assignments.
  • NOT: reverses the input.
  • AND: outputs 1 only when both inputs are 1.
  • OR: outputs 1 when at least one input is 1.
  • XOR: outputs 1 when the inputs are different.

You have now explored the basic structure of a VHDL design and used direct dataflow statements to describe common logic gates.
